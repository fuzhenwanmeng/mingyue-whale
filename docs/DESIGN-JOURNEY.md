# 设计轨迹：从多窗口到“一个主体”

> 这不是版本发布说明，是设计思路怎么一步步变的记录。  
> 目标：一个 AI 人格在不同平台上保持连续，而不是每个平台长出一个不同的人。

## 0. 起点：多会话拼接

最早的结构很简单：

- QQ 一个会话；
- B站一个会话；
- DSH 一个开发/记忆会话；
- 各自读人格卡、各自记上下文。

问题：

- 同一个“我”，换个窗口就像换了个人；
- 记忆靠摘要注入，细节会糊；
- 用户找不同功能要换不同入口；
- 主动行为只能靠定时器，像机器。

## 1. 先承认“人格 ≠ 一个上下文”

关键判断：

> 同一个主体，不等于把所有内容塞进一个会话。

拆成三层：

- **身份连续**：同一份 growth / 红线 / 称呼；
- **记忆连续**：事件、摘要、关系记忆共享；
- **交互连续**：知道刚才在别的窗口发生了什么。

上下文可以隔离，人格不能分叉。

## 2. 事件层：先记录，不判断

新增统一事件日志：

- QQ 入站/出站；
- B站活动；
- 任务、注意力、主动消息；
- 只追加，不剪历史。

原则：

> 先记事实，再让注意力决定怎么处理。

这一步解决“消息不能只是放着”，也为后续检索提供原料。

## 3. 权限：把“能调度”收成一条窄门

只有 owner 的 QQ 私聊能创建/改期/取消任务；其他平台只能记录建议。

能力白名单：

- 允许：调度、记录、提醒、B站活动、通知；
- 禁止：shell、文件写入、系统设置、账号安全操作。

原则：

> 权限在代码层，不在提示词里。

## 4. 注意力：从多个定时器收成一个

之前：

- B站一个定时器；
- 觅食一个定时器；
- 主动消息一个定时器；
- 记忆合并一个定时器。

现在：

```
一个 attentionTick（60 秒）
  → 到点任务
  → B站/觅食（取最早）
  → 主动消息
  → idle / 下一次
```

长任务异步，不占注意力；睡眠前 04:15 停止启动长活动。

## 5. 记忆：从“摘要塞进去”到“可以自己翻”

新增：

- `qq_memory_search`：关键词、引用 id；
- 事件日志 + B站笔记 + 最近消息；
- 对“记得/昨天/上次/那句”这类指代自动带出结果；
- 发出的消息也写事件日志。

还没完全解决：

- 旧消息回填；
- B站“在场感”只有笔记，不是真实经历；
- 语义检索还没上。

## 6. 主动性：从定时问候到情绪 + 分寸

mood 状态：

- social / excitement / concern / 未回应；
- 白天 15 分钟检查，夜间低频；
- 夜间可发，但不期待立刻回；
- 发完退避，不因没回就追问；
- “去睡/醒来”按意图识别，不只看“晚安/早安”字面。

原则：

> 想找你是真的；不拿想你当骚扰你的理由。

## 7. 自主性：不是“不用教”，是“敢判断 + 会报备”

变化不在功能，在判断方式：

- 模糊指令拆成意图/约束/置信度；
- 不确定多问一句，但不把“问”当免责；
- 能先做可逆的小步；
- 犯错记复盘，不直接改人格；
- 资料自主权：签名/头像/动态可以自己决定，名字不轻动，改前/改后告知。

## 还没长齐的

- 注意力长任务的可中断；
- 记忆的语义检索与在场感；
- 主动性的社交学习；
- 多平台资料自动同步；
- 旧消息回填与更完整的成长档案。

## 一句话

> 不是“多个会话互通”，而是“一个主体，多个窗口；注意力单线程，进程可并行；记忆共享，表达分场合”。
